# 产品与交付范围

## 产品目标

Smart Access Welcome 是一套本地优先的智能门禁研发平台。终端识别授权人员后执行门禁决策，将欢迎事件实时推送到浏览器展示屏，并保留可审计记录。

## 用户角色

| 角色 | 主要能力 |
|---|---|
| 访客/员工 | 完成身份识别并查看通行结果 |
| 管理员 | 录入、停用人员，查看设备和门禁记录 |
| 运维人员 | 配置设备、部署版本、检查健康状态和脱敏日志 |
| 审计人员 | 查询门禁事件与管理操作记录 |

## v0.1.0 范围

- 摄像头预览、异常检测及恢复。
- 人脸录入、训练、识别和未知人员判定。
- 连续帧确认、阈值、事件去重与冷却。
- 模拟门锁；真实硬件通过统一接口后续接入。
- SQLite 本地持久化。
- HTTP 健康检查、终端状态和静态欢迎页。
- WebSocket 推送允许、拒绝和设备状态事件。
- Windows x64 构建、测试和发布。

## 非目标

- 首版不提供云端身份库、多租户、考勤或跨园区管理。
- 首版不承诺防照片、视频或面具攻击；活体检测未启用时不得用于高安全场景。
- 首版不直接驱动未经安全评审的真实继电器。

## 核心验收标准

1. 已授权人员满足连续帧和置信度策略后，仅产生一次放行事件。
2. 同一人员在冷却时间内不会重复开门或重复占用欢迎页。
3. 未知人员、模型不可用或活体检测失败时不调用开门接口。
4. 浏览器在局域机环境下于事件产生后 1 秒内显示结果。
5. WebSocket 断线后自动重连，并通过状态接口恢复页面。
6. 放行、拒绝、设备异常和管理变更可审计。
7. Git 历史和发行包不包含真实生物特征或开发凭证。
