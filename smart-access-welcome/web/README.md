# Web welcome client

欢迎页当前作为 UTF-8 静态资源内置在 `modules/access-server` 中，不需要 Node.js 构建链。主程序默认通过 `http://127.0.0.1:8080/` 提供页面；仿真程序在 `8080–8089` 中选择可用端口，并在桌面页面显示实际地址。浏览器通过同源 `/ws` 接收通过、拒绝和终端状态事件，并在重连后读取 `/api/v1/terminal/status`。

本目录保留给未来需要独立版本、主题或 CSP 哈希的前端资源。拆分时必须保持无第三方 CDN、无人员管理能力、无生物特征数据，并补充浏览器端自动化测试。
