# Security Policy

## 支持范围

项目进入首个发布版本后，安全修复仅保证覆盖最新次版本。当前开发版本仅用于研发和受控演示。

## 报告漏洞

请不要在公开 Issue 中提交漏洞利用细节、人脸样本、数据库、密钥或访问记录。仓库所有者应在 GitHub 启用 Private vulnerability reporting，并通过该渠道接收报告。

报告应包含受影响版本、复现条件、潜在影响和不含个人数据的最小复现材料。维护者确认前不要公开披露。

## 明确限制

- 当前 LBPH 原型不具备可靠活体检测能力。
- 开发配置默认只允许本机访问；对局域网开放前必须配置认证、TLS 和防火墙。
- 模拟门锁不得直接用于生产继电器控制。
