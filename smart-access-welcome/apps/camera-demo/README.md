# 摄像头与门禁仿真程序

`CameraSimulationDemo` 用于快速演示画面、识别结果、模拟门锁和浏览器欢迎页，不依赖人脸模型、人员数据库或真实门锁。

- 默认生成动态合成画面，不访问摄像头。
- 可切换到电脑内置或 USB 外接摄像头。
- 模拟通过时推送 `access.granted`，开锁 5 秒后自动复位。
- 模拟拒绝时推送 `access.denied`，门锁保持关闭。
- 欢迎服务优先监听 `127.0.0.1:8080`，占用时尝试至 `8089`。
- `--smoke-test` 自动启动合成画面并触发一次通过事件。

完整构建与操作步骤见 `docs/camera-simulation-demo.md`。
