# ADR-0001：采用本地优先的模块化单体

- 状态：Accepted
- 日期：2026-08-06

## 背景

首版涉及摄像头、识别、门禁控制、数据库和网页推送，部署目标是单台 Windows 门禁终端。过早拆分进程会增加部署、认证和故障处理成本。

## 决策

采用模块化单体：业务边界由 C++ 库和接口保证，终端应用与本地 Web 服务先在同一部署单元运行。跨模块交互使用领域对象或事件，不通过 UI 控件传值。

## 后果

- 首版构建和部署简单，可以复用 Qt 事件循环。
- 模块接口允许未来拆分 Web 服务或集中管理能力。
- 单进程故障影响面较大，摄像头、网络和存储错误必须隔离并拒绝优先。
