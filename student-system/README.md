# 学生管理系统（Student System）

使用 Win32 API 和 C++ STL 开发的桌面学生管理程序，保留对 Visual Studio 2010 的兼容性。

![运行效果](stu.png)

## 功能

- 添加、删除、修改和查询学生信息。
- 展示全部学生记录。
- 在学号升序和成绩降序之间切换排序。
- 使用 `fstream` 将数据持久化到 `students.dat`。
- 使用 Win32 消息和控件构建原生桌面界面。

## 环境要求

- Windows。
- Visual Studio 2010 或更高版本。
- 多字节字符集配置。

## 编译和运行

1. 创建 Windows 桌面应用程序项目。
2. 将 `stumanage.cpp` 加入项目。
3. 在“项目属性 → 配置属性 → 常规 → 字符集”中选择“使用多字节字符集”。
4. 编译并运行。

程序会在当前工作目录生成 `students.dat`。该运行数据已由仓库根 `.gitignore` 排除，不应提交。
